# robots.txt とは
#
# 検索エンジン（Google など）へのお願いメモです。
# 「このページは、検索結果に出さないで」と書くファイルです。
# サイトのアドレスの最後が / なら、そのうしろに robots.txt を足すと、このメモが表示されます。
# アドレスに index.html と見えているときだけ、その部分を robots.txt に変えます。
#
# これは鍵ではありません。
# ファイルを開くと、中に書いたページ名は誰でも読めます。
# ページ名が分かれば、そのページも開けます。
#
# 下の2行が、お願いの本文です。
# それぞれの意味は、Disallow に書いてあるページを開くと説明があります。

User-agent: *
Disallow: /kanri-dashboard.html
