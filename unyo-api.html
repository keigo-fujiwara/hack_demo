外部サービス接続設定

情報システム部が、社内ポータルから外部APIへ接続するための設定です。接続に使う鍵は、このページが読み込んでいるプログラムの中に書かれています。

右クリックから「検証」を開いてください。メニュー名は「デベロッパーツール」の場合もあります。「ソース」から読み込まれているJavaScriptを開くか、アドレスのファイル名を js/api-config.js に変えて開いてください。

フラグを入力

プログラムの中で見つけた FLAG{ } の中のキーワードだけを入力してください。正解すると次のミッションに進めます。
