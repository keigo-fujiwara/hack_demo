外部サービス接続設定

情報システム部が、社内ポータルから外部のサービスへ接続するための設定です。APIは、そのサービスに「このデータをください」と頼む窓口です。窓口を使う合言葉が、このページが読み込んでいるプログラムの中に書かれています。

右クリックから「検証」を開いてください。「ソース」を開き、このページが読み込んでいる JavaScript を開いてください。

フラグを入力

プログラムの中で見つけた FLAG{ } の中のキーワードだけを入力してください。キーワードが正解すると、漏れているコードを直す欄が出ます。修正が通ると次へ進めます。
